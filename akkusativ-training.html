📖 Entdeckung — Der Akkusativ

Was ist der Akkusativ?

Der Akkusativ ist der Fall für das direkte Objekt. Das direkte Objekt ist die Person oder Sache, mit der etwas gemacht wird.

Die Frage lautet: Wen? oder Was?

  • Ich sehe den Mann. (Wen sehe ich? → den Mann)
  • Er kauft einen Computer. (Was kauft er? → einen Computer)
  • Wir trinken den Kaffee. (Was trinken wir? → den Kaffee)

Die Regel: Nur maskulin ändert sich!

der → den  |  ein → einen  |  kein → keinen  |  mein → meinen

Feminin, Neutrum und Plural bleiben im Akkusativ gleich wie im Nominativ!

Nominativ
(Subjekt)		 Akkusativ
(direktes Objekt)
maskulin der / ein / kein den / einen / keinen
feminin die / eine / keine die / eine / keine
neutrum das / ein / kein das / ein / kein
Plural die / – / keine die / – / keine

Wichtige Verben mit Akkusativ

Diese Verben brauchen immer ein Akkusativobjekt:

  • haben — Ich habe einen Hund.
  • brauchen — Wir brauchen einen Tisch.
  • kaufen — Sie kauft den Rock.
  • nehmen — Er nimmt den Bus.
  • möchten — Ich möchte einen Kaffee.
  • trinken — Sie trinkt einen Tee.
  • essen — Wir essen den Kuchen.
  • sehen — Ich sehe den Lehrer.
  • suchen — Er sucht den Schlüssel.
  • finden — Sie findet den Film gut.
  • lesen — Er liest einen Roman.
  • kochen — Ich koche eine Suppe.
🔀 Zuordnung — Nominativ oder Akkusativ?
Nominativ = Subjekt (Wer? Was?). Akkusativ = direktes Objekt (Wen? Was?). Achte auf den Artikel — nur maskulin ändert sich: der → den, ein → einen.
