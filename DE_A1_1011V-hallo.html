🧩 Satzbau

Tipp: Bringe die Satzteile in die richtige Reihenfolge!
🔹 Das Verb steht immer auf Position 2.
🔹 Ich bin / Ich heiße + Name
📨 Schreibwerkstatt
Fünf kleine Schreibaufgaben rund um „Begrüßung". Schreib so viel oder wenig du möchtest — je eine bis 15 Wörter reichen.
Schreiben ist das beste Training. Nimm dir Zeit für eine, zwei oder alle fünf Aufgaben. Jede Antwort kannst du einzeln an mich schicken — du musst nicht alle bearbeiten. Wenn du den Sammelbutton am Ende benutzt, gehen alle noch nicht gesendeten Antworten in einer Mail.
1Dein Name
Wie heißt du? Schreib einen Satz.
Beispiel: „Ich heiße Maria.“
Wörter: 0
2Drei Begrüßungen
Schreib drei deutsche Begrüßungen auf.
Beispiel: „Hallo. Guten Tag. Auf Wiedersehen.“
Wörter: 0
3Eine Frage zum Kennenlernen
Stell jemandem eine kurze Frage.
Beispiel: „Wie heißt du?“
Wörter: 0
4Drei Wörter zur Begrüßung
Nenn drei Wörter aus der Lektion.
Beispiel: „Hallo, tschüss, guten Morgen.“
Wörter: 0
5Mini-Dialog
Schreib einen kurzen Dialog zum Kennenlernen.
Beispiel: „— Hallo, ich bin Maria. — Hi, ich bin Tom.“
Wörter: 0
